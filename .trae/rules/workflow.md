# 开发流程

## 沟通与语言

- 所有回复、注释、提交说明**必须**使用中文；标识符使用英文；不用 emoji。
- 阶段切换一句话；子任务完成一两句总结；收尾直接输出总结，不询问"是否继续"。

## 迭代循环

每次需求默认驱动1到3轮迭代，迭代间不询问。每轮走完6步，**禁止**跳步：

- **收集**：查 CI/CD 失败；扫描 `.trae/designs/` 变更项和待办项；按领域调用 SKILL。
- **计划**：研究既有模式；用任务清单工具拆子任务；优先复用现有抽象；三处相似才提取。
- **实现**：遵守语言 SKILL 与既有风格；优先编辑现有文件；公共 API 须有完整类型签名与中文 docstring；不写未被要求的功能。
- **测试**：公共 API 配套测试，覆盖功能/性能/边界；失败定位根因，不放宽断言；依赖/环境问题先 2 轮自救。
- **文档**：同步更新文档注释/README/`.trae/designs/`下的文件；有价值决策追加到 memory。
- **验证**：逐条对照验收标准；给出变更清单。

未达标准回「收集」；多阶段项目初始确认目标是**整个项目**，阶段完成即自动进入下一阶段「收集」（跨阶段需外部资源时暂停），"整个项目目标达成"不是暂停条件，仅全部交付后才收尾。


## 设计文件要求

### 范围与生命周期

- 设计文件存放于 `.trae/designs/`，按主题一文件，命名 `<主题>.md`；每个文件**必须**仅包含当前生效的设计要求项，历史设计项（已实现并被取代、已废弃）须删除或归档，不得残留。
- 设计文件是需求的落地方案：`.trae/req/` 记录"要做什么"，`.trae/designs/` 记录"怎么做"；两者通过主题命名对应，无对应需求项的设计文件须说明来源。
- 每轮迭代进入「实现」前须确认设计文件已覆盖本轮变更；迭代完成后**必须**同步更新设计文件，使其与代码实际行为一致——设计文件与代码冲突时，以代码为准并立即修正设计文件。

### 内容要素（按适用范围裁剪）

- **接口定义**：对外 API / 函数签名，含参数、返回值、错误语义；修改既有接口须标注行为变化。
- **数据模型**：表结构 / schema / 字段类型 / 约束（required、unique、物理列 vs 逻辑字段等），与 Pydantic / SQLAlchemy 定义保持一致。
- **算法与流程**：核心处理流程的步骤约定（如拆分、下推、两阶段导入等），含边界条件与幂等性要求。
- **异常处理**：错误分类、错误码 / 状态码约定、各层抛出与映射关系。
- **依赖项描述**：被依赖模块、外部服务、数据格式版本（如备份格式版本号），以及跨模块的不变量约束。

### 约束

- 设计文件中**禁止**出现：AI 式表述、`TODO`/`iterate` 占位、无状态的模糊描述（"待定""稍后完善"须改为明确决策或移入 `.trae/req/` 待办）。
- 未实现的设计项须在文件内以 `[ ]` 勾选标记，实现完成后改为 `[x]`，全部完成后清理文件仅保留当前生效设计。
- 设计决策与既有约定（memory / 其他 SKILL）冲突时，优先按既有约定整合；无法自决时按「暂停条件」询问用户，并在设计文件中标注"待用户复核"。

## make check 全局门禁

`make check`（lint/typecheck/cov）以下时机**必须**本地通过：每轮实现完成后、收尾复核时、每次 `git commit` 前。收尾总结须注明"已本地通过 `make check`"。

## 暂停条件

仅以下情况中断找用户：歧义无法自决；高风险/不可逆操作（删除非临时文件、重命名公共模块、`force-push`、工作区未提交时的 `reset --hard`、`git clean -f/-fd/-fx`、改 CI/git config、引入新依赖、改工具链配置、改规则文件（`.trae/rules/`）、卸载降级依赖；普通 commit/push 除外，自动执行）；不可恢复失败（根因不在本仓库/需外部权限/两轮无法定位）；显著超出初始范围；用户主动询问。

可直接自决：测试/lint/类型错误修复、代码风格、文件编辑、运行校验、重命名局部变量、`git clean -fX`、`git stash`/`stash pop`、`git revert`、创建/切换分支、工作区干净时的 `reset --hard`。

## 收尾

全部交付后执行：输出总结（交付物/关键决策/遗留事项）→ 复核 make check 全绿 → `git add` + `git commit`（遵循 Git 提交规范）+ `make push` → 更新 memory；验收未满足则回「收集」。
